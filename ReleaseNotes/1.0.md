# Pinnest 1.0

The first public release of Pinnest, a native macOS menu bar utility for keeping image references floating above your work.

## Highlights

- Pin the newest clipboard image with a menu command or ⌘V.
- Move, rotate, reset, scale toward the pointer, and adjust opacity precisely.
- Drag a pin out as a promised PNG file or copy it back to the clipboard.
- Let mouse input pierce through the image while keeping its toolbar interactive.
- Share a pin across all virtual Desktops or keep it on one Desktop with Stubborn mode.
- Use Launch at Login and signed Sparkle updates from the menu bar.
- English and Simplified Chinese localizations.
